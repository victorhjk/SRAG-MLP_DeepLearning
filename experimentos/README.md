# Evidências dos experimentos

Esta pasta contém os artefatos exportados pelo notebook:

- `exp1_*`: experimento de largura/profundidade e gráficos relacionados.
- `exp2_*`: estratégias de regularização.
- `exp3_*`: histórico, parâmetros e tentativas do Optuna.
- `finalistas_*`: configurações finais, desempenho por semente, curvas e custo-efetividade.
- `teste_*`: resultados finais no teste de 2023, incluindo matriz de confusão, curvas e métricas temporais.
- `importancia_permutacao.*`: análise de importância por permutação.
- `resumo_resultados.json`: resumo serializado de partições, configuração escolhida e métricas.
- `optuna_srag_mlp.db`: banco de dados SQLite do estudo salvo.

Os gráficos e tabelas devem ser interpretados em conjunto com as definições e limitações descritas no relatório e no notebook.
